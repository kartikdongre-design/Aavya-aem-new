================================================================================
  SECURITY NOTES
================================================================================

  - All passwords in JSON files are bcrypt-hashed at rest.
  - Default admin passwords (Admin@123) are for LOCAL DEMO ONLY.
  - Change admin passwords and ADMIN_TOKEN_SECRET before any production use.
  - Do not commit real user credentials to git.
  - Client accounts: create via signup pages; passwords are not recoverable
    from hashed JSON — reset by registering a new email or editing users.json.

================================================================================
  TROUBLESHOOTING
================================================================================

  "Registration failed" / "API server not running":
    → Ensure you start the project with npm start or npm run dev:admin-suite
      (not vite alone). API must be on port 3001 for shopping projects.

  "CSS not applied" (shopping-admin-suite):
    → Run npm install --prefix shopping-admin-suite
    → Restart dev server; hard refresh browser (Ctrl+Shift+R)

  Port already in use:
    → Stop other dev servers (only one app can use 3000 at a time)
    → UrbanNest uses 3200/3201; Admin suite uses 3100; Shop uses 3000/3001

  UrbanNest API not responding:
    → cd urbannest-realty && npm run dev
    → Check http://localhost:3201/api/health
